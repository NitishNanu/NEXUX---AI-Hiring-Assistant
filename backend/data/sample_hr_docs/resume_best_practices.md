# Resume Writing Best Practices — HR Knowledge Base

## Professional Summary
A professional summary should be 2-3 sentences that highlight your most relevant experience, skills, and career goals. It replaces the outdated "Objective" statement.

**Tips:**
- Lead with your title and years of experience
- Include 2-3 key skills or areas of expertise  
- Mention a notable achievement or career goal
- Tailor it to each job application

**Example:**
"Results-driven Software Engineer with 6+ years of experience building scalable web applications using React, Node.js, and AWS. Led a team of 5 developers to deliver a fintech platform processing $2M+ daily transactions. Seeking to leverage my full-stack expertise in a senior engineering role."

## Skills Section
- List 8-15 relevant technical skills
- Group by category (Languages, Frameworks, Tools, Cloud)
- Match skills to the job description keywords
- Include both hard and soft skills

## Experience Section
- Use reverse chronological order
- Start each bullet with a strong action verb
- Include quantifiable results (numbers, percentages, dollar amounts)
- Focus on impact, not just responsibilities
- Use the STAR method: Situation, Task, Action, Result

**Strong bullet point examples:**
- "Reduced API response time by 40% through database query optimization and Redis caching"
- "Led migration of monolithic application to microservices, improving deployment frequency from monthly to daily"
- "Mentored 3 junior developers, resulting in 2 promotions within 12 months"

## ATS Optimization
- Use standard section headers (Experience, Education, Skills)
- Avoid tables, columns, and graphics
- Use standard fonts (Arial, Calibri, Times New Roman)
- Save as PDF unless specified otherwise
- Include exact keywords from the job description
- Use both spelled-out terms and acronyms (e.g., "Machine Learning (ML)")

## Common Mistakes
1. Using generic descriptions instead of specific achievements
2. Including irrelevant experience
3. Typos and grammatical errors
4. Inconsistent formatting
5. Too long (keep to 1-2 pages)
6. Missing contact information
7. Using personal pronouns (I, my, me)
